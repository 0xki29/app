# data/

Inputs of the dictionary build that live in the repository (see scripts/dict/README.md).

- `sources/cedict_1_0_ts_utf-8_mdbg.txt` — the pinned CC-CEDICT export (2026-09-23, 125,101 entries),
  decompressed, byte for byte as MDBG's `.gz` unpacks (CRLF; bytes and SHA-256 of the text and of the
  original `.gz` in scripts/dict/sources.lock.json). CC-CEDICT, published by MDBG; CEDICT © 1997,
  1998 Paul Andrew Denisowski. CC BY-SA 4.0. Kept here because MDBG's URL always serves the latest;
  kept as text because git stores a refresh as a small delta, where a new `.gz` would add its whole
  3.8 MB to every clone. `.gitattributes` keeps its bytes exact (`-text`).
- `overrides/` — curated data, CC BY-SA 4.0 (derived from CC-CEDICT and CVDICT): `vi-gloss.tsv`
  (Vietnamese glosses), `hanviet-word.tsv` (word readings, `-` for loanwords), `hanviet-char.tsv`
  (character readings, and the vernacular forms that must never ship), `extra-entries.tsv` (HSK words
  CC-CEDICT lacks), `join-deny.tsv` (CVDICT joins known to be wrong), `not-proper-noun.tsv` (common
  nouns CC-CEDICT capitalizes), `CHANGELOG.md`. Rows are `ai-draft` until the owner marks them
  `reviewed`.
- `golden/hanviet-gold.tsv` — 46 hand-checked polyphone readings, a build gate (the algorithm may
  miss 2, the shipped column none).
- `golden/search-queries.tsv` — what a learner types → the entry that must come first; checked by
  `npm test` on the built dictionary (`scripts/dict/test/golden-search.test.mjs`).
- `licenses/` — license texts shipped with every build: the CC BY-SA 4.0 legal code and the Unicode
  License V3 (the MIT and Arphic texts come from their packages).
- `build-report.json` — generated by `npm run data:build`: counts, coverage, gate results and sizes of
  the current data. Committed so that data changes are visible in review.
